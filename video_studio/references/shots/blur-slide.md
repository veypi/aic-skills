---
name: blur-slide
一句话: 标题逐词从虚焦里浮出——位移+模糊+透明度三通道同一条 ease-out 同步收敛
适用: 几乎所有标题/副标题成对场合；"专业但不抢戏"的默认文字 reveal
时长: 2–3s（词间隔 0.13s，副标题在标题收完前错峰跟进）
能量: 低（一次性收敛，无峰值）
依赖: stagger, blur
---

## 意图
文字 reveal 的默认解。专业感全来自一件事：y、blur、opacity 共用同一进度同一条缓动——词是"从虚焦里浮出来"而不是"滑进来又变清楚"两个动作。

## video_studio/1 配方

```jsonc
// 每个词独立 text；y、opacity、blur 在同一段关键帧里同步收敛
{ "id": "word-0", "type": "text", "x": 140, "y": 260, "w": 320, "h": 110,
  "html": "Make", "fontSize": 96, "fontFamily": "Georgia, serif", "color": "#1c1b19",
  "keyframes": [
    { "t": 0.2, "y": 324, "blur": 18, "opacity": 0 },
    { "t": 0.93, "y": 260, "blur": 0, "opacity": 1, "easing": "bezier(0.16,1,0.3,1)" }
  ] }
// word-1 起点 delay +0.13s，依此类推；副标题在标题收完前 0.3s 跟进
```

完整排版参考内置样例 `Lumen · 1.1 能力演示` 的第二幕：刊头、发丝线、刊号、主副标题与页脚共同构成完整页面，首帧不留空黑场。

## 已知坑
- 三通道必须同缓动同时值；分开调读作"两个动画"
- 词间隔 0.13s（4f）：太大读作打字机，太小读作整体淡入
- 副标题字号 ≥ 标题 45% 且达 Q11 有效字高线
