---
name: card-stack
一句话: 一组卡逐张 spring 弹入越落越快叠成一摞，落位后一次性展成扇面，中心卡被抽出
适用: "我们有一组东西"的段落；模板库/方案列表建立镜头
时长: 4–5s（叠摞 2s + 展扇 0.8s + 抽卡 0.6s + hold）
能量: 中高（入场连续小爆发，展开收成一次平滑整体动作）
依赖: keyframes(spring), rotation
---

## 意图
先给"整体"再给"个体"：第一眼记住有分量的一摞（数量感），第二眼才看清每张不一样（多样性）。展开留到最后一次性完成，不和入场节拍打架。

## video_studio/1 配方

```jsonc
// 6 张卡同落点叠摞（微错位），delay 递减；展扇 = 各卡 rotation/x 按序号偏移
{ "id": "tpl-0", "type": "image", "src": "assets/tpl-0.png", "x": 490, "y": 240, "w": 300, "h": 200, "radius": 10,
  "keyframes": [
    { "t": 0.2, "y": 760, "opacity": 0 },
    { "t": 0.8, "y": 240, "opacity": 1, "easing": "spring(11,140,1)" },
    { "t": 2.4, "rotation": 0, "x": 490 },
    { "t": 3.2, "rotation": -16, "x": 250, "easing": "easeInOut" },   // 展扇：序号×6.5°/138px
    { "t": 4.5, "rotation": -16, "x": 250 }
  ] }
// tpl-i 展扇目标：rotation = (i - 2.5)×6.5°，x = 490 + (i-2.5)×138
// 抽卡：中心卡 t 3.6→4.2 y -40 + scale 1.08，其余卡 opacity 0.55
```

## 已知坑
- 叠摞段微错位（±3px/±1°）才有"一摞"的厚度，完全重合读作一张
- 展扇一次性整体动作（同 t 起同缓动），别逐张展——和入场节拍打架
- 抽出后 hold ≥1s（R1）；卡素材 2x（Q2）
