### 5.4 智能体集群模块（重写）

> 以下为完整新内容。

智能体集群模块是智能底座的运行执行层，向上承载合规审查、风险分析、情报分析、专家辅助、报告生成、预警研判等业务智能体，向下调用知识库模块（5.1）的知识检索与规则匹配服务、大模型训练模块（5.2）的推理服务、样本与案例库模块（5.3）的案例检索服务，为监管人员和企业用户提供智能化分析和辅助决策支撑。

---

#### 5.4.1 模块定位与建设目标

**① 在智能底座中的定位**

智能体集群模块位于智能底座四层架构的最上层（运行执行层），其角色是：

- 对上层业务：承载各类业务智能体，面向监管人员和企业用户提供交互界面和分析服务
- 对下层能力：调用知识库模块的知识检索与规则匹配服务、大模型训练模块的推理服务、样本与案例库模块的案例检索服务
- 对业务流程：串联"知识检索—模型推理—智能分析—结果生成—人工复核—处置归档"的闭环链路

**② 核心建设目标**

- 建成不少于 5 类业务智能体（合规审查、风险分析、情报分析、专家辅助问答、报告生成），支持预警研判智能体扩展
- 提供多用户安全隔离能力，保障不同用户使用同一智能体时数据与会话互不可见
- 提供智能体自定义前端界面能力，满足不同业务场景的差异化交互需求
- 提供智能体私有动态数据库能力，支撑各业务智能体按需灵活存储业务数据
- 支持多智能体任务协作，实现复杂业务场景下的智能体间工作协同

**③ 与其他模块的依赖关系**

| 依赖模块 | 依赖能力 | 用途 |
|---------|---------|------|
| 知识库模块（5.1） | 法规检索、规则匹配、模板调用 | 合规审查依据、报告生成模板 |
| 大模型训练模块（5.2） | 专业模型推理服务 | 智能体语义理解与分析推理 |
| 样本与案例库模块（5.3） | 相似案例检索 | 审查参考、专家辅助推荐 |
| 统一认证服务 | 用户身份认证 | 访问鉴权与数据隔离 |
| 统一文件存储 | 文件持久化 | 智能体配置与界面文件存储 |

---

#### 5.4.2 智能体运行基座能力

**① 智能体生命周期管理**

- 智能体创建：支持创建面向特定业务场景的智能体，设置名称、描述、默认模型和知识绑定配置。每个用户至少拥有一个默认智能体
- 智能体配置：支持配置系统指令（决定智能体的行为逻辑和业务规则）、知识绑定、交互参数等
- 状态管理：智能体支持启用和停用两种状态，停用后不再接受新的会话请求
- 版本管理：智能体的系统指令和数据结构定义应支持版本管理，可追溯变更历史和回滚

**② 知识绑定能力**

- 智能体可按需绑定知识库模块（5.1）中的审查规则、报告模板等知识资源
- 绑定模式分为两类：强制约束模式（智能体必须严格遵循知识定义的规则和约束）和参考知识模式（智能体按需调用知识内容作为参考）
- 知识更新后，已绑定智能体在后续会话中自动应用最新版本

**③ 会话管理**

- 用户与智能体的每次交互以会话为单元
- 会话状态流转：创建 → 活跃 → 等待（人工审批挂起）→ 活跃 → 完成/异常
- 会话需维护完整对话历史
- 支持长时间会话的对话历史自动整理，保障交互连贯性
- 审批、处罚、预警类结论不得自动最终决定，会话应在关键决策点挂起等待人工审批确认

**④ 任务调度**

- 支持在智能体会话中创建后台任务
- 任务类型：一次性任务、定时任务（按时间计划执行）、周期任务（按固定间隔重复执行）
- 任务执行时自动向关联会话发送状态提醒
- 典型定时任务场景：企业风险画像定期更新、行业情报日报生成、法规更新检测、审查案件逾期提醒等

**⑤ 多智能体协作**

- 支持多类业务智能体同时运行，共享底层基础设施资源
- 智能体可设为共享状态，供其他用户发现并创建会话
- 智能体可设为可复制状态，允许其他用户完整复制配置后进行二次定制，副本修改不影响原智能体
- 一个会话中的智能体可向其他智能体分派子任务，子任务完成后结果自动回传父会话，实现任务级协作（如报告生成智能体调用合规审查智能体获取审查结果）

**⑥ 外部消息接入**

- 支持通过即时通讯工具与智能体交互
- 外部平台会话与系统内部会话自动映射，保持上下文连续性
- 外部消息支持指令路由（特定前缀消息执行对应命令：帮助、状态、新建会话、切换智能体等），普通消息转发至对应智能体会话处理
- 关键决策点（审批、处罚、预警结论）支持通过外部消息推送审批请求，审批人确认后继续执行

#### 5.4.3 多用户安全隔离

**① 会话级用户隔离**

不同用户使用同一智能体时，彼此的会话彼此独立、互不可见。每个会话同时记录智能体所有者标识和实际使用者标识。

**② 数据行级隔离**

智能体私有数据库中所有业务数据按用户维度自动隔离。用户仅能访问自身创建的数据记录，系统自动标注数据归属并强制过滤。

**③ 数据共享模式**

针对知识库、企业基础信息等需全员可查的数据，支持设为"全员可读"模式——所有用户可读取全部记录，但仅数据所有者或授权管理员可修改或删除。

**④ 访问控制矩阵**

| 操作 | 智能体所有者 | 授权用户 | 未授权用户 |
|------|:---:|:---:|:---:|
| 查看智能体信息 | 允许 | 允许 | 禁止 |
| 修改智能体配置 | 允许 | 禁止 | 禁止 |
| 创建会话 | 允许 | 允许 | 禁止 |
| 读写自身数据 | 允许 | 允许 | 禁止 |
| 跨用户数据操作 | 允许 | 禁止 | 禁止 |
| 复制智能体 | 允许 | 允许（需开启） | 禁止 |

---

#### 5.4.4 智能体自定义前端界面

**① 独立界面能力**

每个智能体可拥有独立的 Web 前端界面。智能体所有者可根据业务场景需求自定义界面布局、交互方式和信息展示维度。不同业务智能体应具备差异化的界面能力：

- 合规审查智能体：材料对照视图、发现项列表、审查意见编辑区
- 风险分析智能体：企业风险评分仪表盘、多维指标雷达图、风险趋势时间线
- 情报分析智能体：行业动态时间线、企业关系图谱、政策变化追踪
- 专家辅助问答智能体：法规依据检索区、相似案例推荐区、对话交互区
- 报告生成智能体：报告模板选择、章节编辑、数据汇总预览

**② 默认界面回退**

未自定义界面的智能体自动使用系统默认界面。默认界面应呈现智能体基本信息（名称、描述、状态）、运行统计和使用入口。

**③ 界面隔离**

多个智能体的前端界面在同一系统中运行时应具备组件级和样式级隔离，互不干扰。

**④ 界面访问权限**

- 非共享智能体的界面仅限智能体所有者访问
- 共享智能体的界面所有授权用户均可访问
- 未登录或未授权用户应被拒绝访问并提示

#### 5.4.5 智能体私有数据库

**① 动态建表能力**

智能体应按业务需要自行创建私有数据表，无需预定义固定表结构。表结构以结构化配置方式定义，包含字段名称、类型、标题、是否必填、默认值和可选值约束。

各业务智能体预计所需数据表类型（示例）：

| 智能体 | 数据需求示例 |
|--------|------------|
| 合规审查 | 审查案件表、发现项明细表、审查结论表 |
| 风险分析 | 企业风险档案表、活动风险评分表、风险指标配置表 |
| 情报分析 | 企业信息表、发射活动表、行业动态表、融资记录表 |
| 报告生成 | 报告记录表、报告模板配置表 |
| 专家问答 | 对话记录表、高频问题库 |

**② 表结构变更**

智能体业务数据表应支持新增字段，新增字段不应影响已有数据的完整性和正常读写。

**③ 数据接口**

- 每张数据表应自动具备基本数据操作能力（新增、查询、修改、删除）
- 数据查询应支持分页、排序和多条件筛选
- 智能体所有者应支持执行跨表统计查询，用于数据分析和报表导出

**④ 数据归属**

每张数据表应自动记录数据归属用户、创建时间和更新时间，且用户不可修改这些自动记录字段。

#### 5.4.6 业务智能体定义

**① 合规审查智能体**

- 用途：对申报材料进行完整性、合规性人工智能初审
- 调用能力：知识库模块的审查规则匹配、样本与案例库模块的相似案例检索
- 输入：企业申报材料（任务备案、发射许可、遥感数据合规、频率使用等）
- 输出：材料完整性检查结果（缺项清单）、合规性检查结果（规则冲突点、风险提示）、审查发现项明细和审查意见初稿
- 关键约束：审查结论须经人工复核确认，不得自动最终决定

**② 风险分析智能体**

- 用途：综合企业资质、历史许可、发射记录、事故事件、整改情况、舆情情报等数据，生成企业风险画像和活动风险评分
- 调用能力：知识库模块的风险判定规则
- 输入：企业多维数据（基础信息、许可记录、发射历史、事故记录、舆情情报）
- 输出：企业风险画像（综合评分、分项评分、风险等级）、活动风险评估报告、重点风险提示清单
- 关键约束：高风险预警须经人工审批后发出

**③ 情报分析智能体**

- 用途：跟踪国内外商业航天政策、企业动态、发射活动、重大事故、技术发展趋势，生成情报分析成果
- 输入：互联网公开信息、行业报告、政策文件
- 输出：行业动态日报/周报、专题情报分析报告、趋势研判、风险预警建议
- 关键约束：情报来源须标注，分析结论须标注置信度

**④ 专家辅助问答智能体**

- 用途：为监管人员提供法规依据检索、相似案例推荐、审查建议和处置参考
- 调用能力：知识库模块的法规检索、样本与案例库模块的相似案例检索
- 输入：监管人员提出的业务问题（法规咨询、案例查找、审查建议请求等）
- 输出：相关法规条款及解读、相似案例列表及相似度排序、参考建议
- 关键约束：建议应标注依据来源，涉及处置决策的须提示以人工判断为准

**⑤ 报告生成智能体**

- 用途：自动生成审查意见书、风险评估报告、情报分析报告、监管专报等报告初稿
- 调用能力：知识库模块的报告模板调用；可调用其他智能体（合规审查、风险分析、情报分析）获取分析结果
- 输入：报告类型、目标对象、数据来源（审查结果、风险评分、情报摘要等）
- 输出：符合模板规范的报告初稿
- 关键约束：报告初稿须经人工审核修订后方可定稿发布

**⑥ 预警研判智能体**

- 用途：对重点企业、重点任务和异常事件进行综合研判，辅助形成风险预警建议
- 调用能力：综合调用风险分析智能体和情报分析智能体的分析结果
- 输入：重点监控对象列表、异常事件信息、风险评分数据
- 输出：预警研判报告、预警等级建议、处置措施建议
- 关键约束：预警发出前须经人工审批确认

#### 5.4.7 非功能需求

**① 性能要求**

| 指标 | 要求 |
|------|------|
| 并发智能任务 | 不少于 50 路 |
| 普通智能问答响应 | 不高于 5 秒 |
| 知识检索响应 | 不高于 3 秒 |
| 相似案例检索响应 | 不高于 5 秒 |
| 单次数据操作 | 低于 500 毫秒 |
| 常规许可材料人工智能初审 | 不高于 10 分钟 |
| 单份报告初稿生成 | 不高于 3 分钟 |

**② 容量要求**

| 指标 | 要求 |
|------|------|
| 业务智能体数量 | 不少于 5 类，可扩展 |
