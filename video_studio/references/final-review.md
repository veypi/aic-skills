# 独立终检

制作者对自己的产出有确认偏差，**首检永远不能交给用户**（P1）。交付前派一个干净上下文的 subagent 做独立审查。

## 发起

用 delegate 工具起后台任务，goal 模板：

> 你是独立视频质检员。存档：/fs/{source}/.../demo.video_studio（按所属端用 fs 工具读取）。
> 输入：主 .video_studio（含分镜 brief.md）、镜头卡名清单、审美准则。
> 步骤：1) 读 brief.md 与主存档；2) 打开 Video Studio 页面（open /skills/cloud/{skill_id}），open_video --path /fs/.../demo.video_studio；
> 3) 逐场景 shot_video 抽关键帧（入场帧/动作帧/hold 帧各一），fs.read 查看；
> 4) 按下方清单逐条出报告，每条带帧号证据；5) 只报告不修改。

## 审查清单

**方案一致性**
- [ ] brief.md 功能清单每项有对应镜头（P4）
- [ ] 一种手法没有两次当主角；无重复信息镜头（P4）
- [ ] 视觉 tokens 与产品一致，没有不相干的宣传片皮肤
- [ ] 动态时间码、页码、总数与当前场景 duration/镜头顺序一致

**节奏**
- [ ] 关键信息落定 hold ≥1s，品牌字标 hold 满 1s（R1）
- [ ] 无匀速直线运动；批量入场加速 + 收尾 0.5s 静止（R2）
- [ ] 开场主体动作弧 ≥3s（R3）
- [ ] 全画面级冲击 ≤3 处（R4）

**画面**
- [ ] 每幕入场/动作/hold 至少三帧截图并实际查看；拼图用于总览，可疑处必须再看全尺寸单帧
- [ ] 无越界/穿帮/意外抖动（Q3）；Three 主体完整且取景中心正确
- [ ] 视觉对齐：文字有正确的 align/valign，多行标题共轴，状态图标贴近实际文字，轨道标签各自对准槽位（Q12/Q13）
- [ ] 特写文字锐度：素材分辨率够（Q2），shot_video --scale 2 裁剪放大验
- [ ] 有效字高：字幕 ≥5% 帧高、辅助 ≥3%；缩到 480px 宽仍可读（Q11）
- [ ] sheen 不群发、被圆角裁剪（Q4）
- [ ] 飞入元素落在真实槽位（Q9）
- [ ] 结尾能量 ≥ 全片其他段落（Q8）

**声音**
- [ ] sfx 每条有 note 且 t 对得上动作帧（S2）
- [ ] 无游戏音色；拟音与动作等长（S1/S4）
- [ ] 改过时间线的话 sfx 已重钉（S3）

**文案**
- [ ] 文案与画面匹配；无 >3s 哑巴段落（C1）
- [ ] 标语含功能名/具体收益（C2）

**技术回归（制作者先执行）**
- [ ] 所有 JSON 可解析，改动 JS 通过语法检查，UI 通过 `vhtml check`
- [ ] 全片每一帧执行一次 `buildFrame` 并检查新增错误；这只能证明可运行，不能代替三帧视觉审查
- [ ] 修改过 Three 相机/几何时，预览与导出路径都至少截一帧核对

## 报告格式

```
镜头 S2（f30–f90）
  R1 ✓  hold f66–f90 = 0.8s ✗ 不足 1s → 建议 duration +0.3s
  Q11 ✗  副标题 20px < 22px（720p）→ 提到 24px
  ...
结论：N 处必修 / M 处建议
```

必修项改完后**再截帧复验**，然后把报告摘要交给用户。
