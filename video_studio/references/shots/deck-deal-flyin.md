---
name: deck-deal-flyin
一句话: 一摞卡像发牌一样硬加速甩进网格，越来越快，满板后静止 0.5s
适用: "内容量大/源源不断汇入"的列表页与卡片墙；信息密度第一印象
时长: 4–5s（发牌 2.5–3s + 满板 hold ≥0.5s）
能量: 高（节奏爬升段主力，不放开场第一镜）
依赖: keyframes(加速错峰), camera
---

## 意图
观众要感受到"东西源源不断涌进来"，每张卡带着急迫感砸到位。抽象 flood 不收敛时换发牌隐喻：从同一叠起点、沿弧线、硬加速、逐张到位。

## video_studio/1 配方

```jsonc
// 8 张真实内容卡飞入 2×4 网格；delay 递减 + easeIn 硬加速；起点同为右下角牌堆位
// 生成逻辑（run_js 或手写）：delay_i = 0.3 + Σ(0.34·0.82^k), k<i
// opacity 在整段飞行中连续变化；禁止加 0.04s 中间帧把卡片突然跳亮
{ "id": "card-0", "type": "image", "src": "assets/card-0.png", "x": 120, "y": 120, "w": 260, "h": 150, "radius": 10,
  "keyframes": [
    { "t": 0.30, "x": 1050, "y": 620, "rotation": 12, "scale": 0.8, "opacity": 0 },
    { "t": 0.72, "x": 120, "y": 120, "rotation": 0, "scale": 1, "opacity": 1, "easing": "easeIn" }
  ] }
// card-1: delay 0.64 → 1.02；card-2: 0.92 → 1.26；card-3: 1.15 → 1.45 …间隔×0.82 递减
// 相机：发牌段从牌堆特写缓升满板俯瞰
"camera": { "keyframes": [
  { "t": 0, "zoom": 1.5, "focus": [1080, 640] },
  { "t": 2.8, "zoom": 1, "easing": "easeInOut" },
  { "t": 4.5, "zoom": 1 }                                   // 满板 hold 0.5s+
] }
```

## 参数手感
| 参数 | 典型值 | 调节 |
|---|---|---|
| 间隔衰减 | ×0.82/张 | 匀速间隔读作 PPT（R2）；衰减太狠后段糊成一片 |
| 单张飞行 | 0.3–0.45s easeIn | easeOut 读作"飘到位"，没有砸感 |
| 起点旋转 | 8–14° | 牌感；落位必须 0°（Q9 真实槽位） |

## 已知坑
- 终点 = 网格真实坐标（Q9），先算好布局再写关键帧
- 卡片用真实截图或信息完整的原创内容；禁止空矩形 + 一行标签冒充内容卡
- 开场必须有可读构图：真实牌堆、页面底板或低对比槽位至少一种；不能让观众盯着空黑场等卡片
- 透明度随整段运动连续插值；禁止单帧从 0 跳到 1 的“闪现”
- 满板后静止 ≥0.5s 再切（R2）；SFX 逐张 pop 音量阶梯 0.4→0.25 + 间隔加速（S2）
- 批量入场不逐个发光（Q4），靠运动本身
