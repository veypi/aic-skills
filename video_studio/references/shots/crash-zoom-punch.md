---
name: crash-zoom-punch
一句话: 全景一拍急推到目标特写（0.2s），落位过冲回弹或撞停震屏
适用: 功能段"点名"镜头——把视线一拍按到目标卡/模块上
时长: 全景 hold ≥1s + 动作 0.4s + 特写 hold ≥1.5s
能量: 高（瞬时冲击，非持续高能）
依赖: camera
---

## 意图
慢推近是"请看"，急推是"看这个！"。回弹款是弹性（"看这个"），撞停款是重量（"就是它"），按强调级选，两款别混用。

## video_studio/1 配方（撞停款）

```jsonc
"camera": {
  "keyframes": [
    { "t": 0, "zoom": 1 },
    { "t": 1.0, "zoom": 1.03, "easing": "linear" },                          // 全景极缓 creep
    { "t": 1.13, "zoom": 0.97, "easing": "easeOut" },                        // 预备回拉 3%
    { "t": 1.33, "zoom": 2.4, "focus": [820, 400], "easing": "easeIn" },     // 6f 急推
    { "t": 3.5, "zoom": 2.4, "focus": [820, 400] }                           // 特写 hold
  ],
  "shakes": [ { "t": 1.33, "amp": 12, "decay": 0.06, "dur": 0.22, "freq": 28 } ]
}
// 回弹款：去掉 shakes，急推终点 zoom 2.55，+0.17s 回收到 2.4（easeOut）
```

## 参数手感
| 参数 | 典型值 | 调节 |
|---|---|---|
| 急推时长 | 0.2s（0.13–0.27） | >0.33s 读作普通推近 |
| 目标 zoom | 2.4–2.8 | 终点构图以目标占画面 60–75% 为准 |
| 回弹幅度 | zoom 的 3–6% | 过大读作弹簧玩具 |
| 震屏 | amp 12 · decay 0.06 | amp >20 读作故障；<8 无感 |

## 已知坑
- 终点全程特写目标：素材必须高清（Q2），focus 坐标先量准
- 一支片急推 ≤2 次（P4）；撞停震屏计入全画面冲击 ≤3 处名额（R4）
- 急推前全景 hold ≥1s 建立空间，否则观众不知道推的是哪里
- SFX：whoosh 钉急推起点、impact 钉到位帧（sound-design 句式）
